主な仕事

インフラ／OS移行

保険会社向け Windows 10 → 11 大規模OS移行

500名規模のOS移行でサブリーダーを担当。アプリの非互換リスク分析から改修・テストまで一貫して進めました。Microsoftやベンダーとの技術照会で仕様を早めに解消し、移行トラブルを未然に防いでいます。テスト計画・仕様書の策定を主導し、全工程で品質を担保しました。

  • Windows 11
  • SASE（クラウド型セキュリティ）
  • ID管理基盤
  • PowerShell
  • VBScript
  • ウォーターフォール

C# / .NET モダナイズ

物流業界向け会計システムのリニューアル

既存システムをWindows Formsアプリへ刷新。スクラムで詳細設計から単体テストまでをスプリント単位で進め、他メンバーのコードレビューも担当して品質基準を保ちました。

  • C# / .NET
  • Windows Forms
  • スクラム

クラウド移行／Go API

AWS → GCP 移行に伴う RESTful API 開発

Go 1.19でバックエンドAPIを製造し、単体〜結合テストで品質を担保。GitHubのプルリクエストを軸にした開発で、仕様変更にも素早く対応しました。

  • Go 1.19
  • Google Cloud
  • GitHub
  • スクラム

C# UWP／WebRTC

教育機関向け Web講義システムのネイティブアプリ化

PHP/JSのWebシステムをC#（UWP）のアプリへ再構築。WebRTCで低遅延の映像・音声配信を実装し、Windows 10/11での動作検証を徹底しました。

  • C# UWP
  • WebRTC
  • JSON
  • Visual Studio
